# 使用说明

## 工程结构与构建

完整工程位于 `HX4S20_HDMI/`：`SD/` 为 TF/FAT32 和 SDRAM 数据通路，`audio/` 为 PCM 播放与音源管理，`display/` 为菜单、OSD 和转场，`IP/`、`include/`、`hdmi1.4b_transmitter_core/` 为所需 IP 与头文件，`constraints/` 为引脚与时钟约束，`board/` 为板级顶层、构建与仿真入口。

克隆后先在仓库根执行 `python HX4S20_HDMI/tools/submission/prepare_project.py`，按本机工程实际位置设置 TD Project Path，再在安路 TD 6.2.168116 中打开 [工程文件](../HX4S20_HDMI/HX4S20_HDMI_Config.al)，确认器件为 `EG4S20BG256`、顶层为 `hx4s20_board_top`，使用 HDMI A 接口。仓库中的 Project Path 为 `.` 占位；小工具会仅更新这一个本机路径，不改变 RTL/IP/约束，也无需将本机路径提交回仓库。交付校验器允许此项本机路径转换并继续检查其他字节。

命令行构建前，将 TD 的 `td_commands_prompt.exe` 所在目录加入 PATH，在 `HX4S20_HDMI/` 执行：

```powershell
python tools/menuflow/run_td_build.py
```

包装脚本会登记音频/波形源文件再执行综合、布局、布线、时序与 bitgen。TD 可能在打开工程时重写源文件表；构建后须确认 `audio/` 四个源文件和 `display/audio_waveform_overlay.v` 均保留。可下载文件与报告位于 `HX4S20_HDMI_Config_Runs/phy_1/`。重新构建会改变位流，发布快照清单的哈希也随之失效；请记录新文件 SHA-256 和同次时序报告，四项裕量非负后再下载。

## TF 卡素材

准备 FAT32 TF 卡，将四张 [菜单图片](../HX4S20_HDMI/assets/menu/) `PIC1.BMP`～`PIC4.BMP` 复制到卡根目录。必须四张齐全；图片为 640×480、24 位、无压缩 BI_RGB、正高度 BMP（每张 921654 字节）。FAT32 读取器按固定 8.3 文件名识别并沿 FAT 簇链读取；不支持任意分辨率、自适应缩放、亮度对比度调节或缩略图选择。

促销语音使用 [promo/PIC3.PCM 与 PIC4.PCM](../HX4S20_HDMI/assets/tf_audio/promo/)，同样复制到卡根目录。文件格式为 **48 kHz、16 位有符号、小端、单声道、无文件头**；不要将 WAV/MP3 直接改扩展名。`assets/tf_audio/` 中另有原测试音频，可用于替换同名 PCM；`promo/` 中的 WAV 只供电脑试听。PCM 缺失不阻止图片初始化。第3/4页播放对应音轨；无 WAV/MP3 解码器。

`assets/tf/001.bmp`～`004.bmp` 是仿真回归输入，文件名不同于上板菜单素材。不要将其与卡根目录的 `PIC*.BMP` 混淆。

## 按键

以下名称为板上物理按键丝印；与 RTL 的 `key1/key2/key3` 分别相差一位。

| 按键 | 正常显示模式 | 商品管理模式 |
|---|---|---|
| KEY1 | 复位，上电后重新加载 | 复位，售罄标记清零 |
| KEY2 | 下一页 | 循环选择当前页四个商品 |
| KEY3 | 短按切换自动轮播；长按约1秒上一页 | 短按切换选中商品在售/售罄 |
| KEY4 | 短按进入商品管理 | 短按退出商品管理 |

管理模式期间暂停轮播并屏蔽翻页；退出后有短暂按键释放保护。仅第1/2页允许修改售罄状态；第3/4促销页不允许编辑商品。菜单短按在释放时触发，约600～800 ms的模糊按压区间及管理长按不执行编辑；建议清晰短按。

## 仿真和静态核验

在仓库根目录执行：

```powershell
python HX4S20_HDMI/tools/submission/verify_submission.py
python HX4S20_HDMI/board/verify_pin_report.py
python HX4S20_HDMI/board/run_regression.py
python HX4S20_HDMI/board/fat32/run_rtl_fixture_matrix.py
```

既有回归脚本使用 Windows Icarus Verilog 路径 `C:/iverilog/bin`；若工具安装在其他位置，应调整脚本中的 compiler/runtime 路径。ModelSim 音频入口 `board/run_modelsim_audio.py` 默认使用 `D:/altera/14.1/modelsim_ase/win32aloem`。仿真会生成被 Git 忽略的临时输出，不能覆盖物理 HDMI/TF 电气和完整 IO/CDC 验收。

本次整理未改业务 RTL/IP/约束；验证证据和位流来源参见 [下载与验证](下载与验证.md)。
